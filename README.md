# Vinayak Prajapati — Portfolio Website

A single-file, self-contained personal portfolio website for **Vinayak Prajapati**, final-year Computer Science Engineering student (Sandip University, Nashik) seeking entry-level roles in **Data Analytics / Data Engineering**.

## 📄 File
- `portfolio.html` — the entire website (HTML, CSS, and JavaScript in one file, with all images, the résumé, and certificates embedded as base64 so no external files are needed).

## ✨ Sections
1. **Hero** — name, photo, animated role marquee (Data Analyst / Data Engineer / Computer Science Student), résumé download, contact CTA
2. **About Me** — short professional summary
3. **Education** — SSC (CBSE), HSC (Maharashtra State Board), B.Tech (Sandip University)
4. **Skills** — three cards: Data Analytics, Data Engineering (incl. concepts currently being learned), and Tools, plus a Soft Skills card
5. **Projects** — Abnormal Behaviour Detection for Road Safety, To-Do List Application
6. **Experience** — AI Data Analytics Internship at Inamogos/InAmigos Foundation, with buttons to view the internship certificate and offer letter
7. **Certifications** — 6 certifications, each with a "View certificate" button that opens the real certificate image/PDF in a popup
8. **Get in Touch** — contact cards (Email, WhatsApp, LinkedIn) plus a message form that opens the visitor's email client with the message pre-filled
9. **Footer** — quick links and social links (Email, WhatsApp, LinkedIn, GitHub, Instagram, Facebook)

## 🎨 Features
- Dark/light theme toggle (persists via `localStorage`)
- Scroll-triggered fade-up animations on cards, certifications, and skill tags
- Fully responsive layout
- All documents (résumé, certificates, offer letter) embedded directly in the HTML — nothing external to host or link

## 🛠️ Tech
Plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step. Fonts loaded from Google Fonts (Fraunces + Inter).

## 🚀 How to Use
- **View locally:** open `portfolio.html` in any browser.
- **Host anywhere:** upload `portfolio.html` to any static host (GitHub Pages, Netlify, Vercel, etc.) — it works as-is with no configuration.
- **Edit content:** search the file for the relevant text (e.g. certification names, skill tags) and update directly, or ask Claude to make further edits.
